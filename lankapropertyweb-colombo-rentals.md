> session's network egress policy, and the site sits behind Cloudflare bot

> **harvested from public search-engine indexing** of the site — so it is a
> representative sample of real, currently-listed properties (with their real
> detail-page URLs and prices), **not** the exhaustive page-by-page crawl of
> every result and every inner page.
>
> **To get the full, complete scrape:** enable network access for
> `api.firecrawl.dev` + `www.lankapropertyweb.com` (see `README_lankaproperty.md`),
> then run the committed scraper `scrape_lankaproperty.py`. It will follow every
> listing into its inner property page and dump everything to text/JSON.

## How to complete this into a full scrape

1. Allow `api.firecrawl.dev` and `www.lankapropertyweb.com` in the environment's
   **Network access → Custom → Allowed domains** (keep the default package-manager list ticked).
2. Run:
   ```bash
   pip install -r requirements.txt
   export FIRECRAWL_API_KEY="fc-...."
   python scrape_lankaproperty.py
   ```
3. Outputs `scraped_data.txt` + `scraped_data.json` with every listing and every
   inner property page fully scraped.
